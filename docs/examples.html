Examples

Six programs that cover the full surface of the language

Calculator

Arithmetic helpers, guard-clause early returns, and multi-argument functions. Shows how grow replaces function, and guard clauses (=>) replace if/return for simple checks.

Fibonacci

Recursive Fibonacci with a guard clause base case. The guard n <= 1 => harvest n is a one-line early exit — semantically identical to if (n <= 1) return n in JavaScript, but without the braces or the keyword noise.

Loops & Control Flow

Demonstrates cycle (while loop), dormant (continue), wither (break), and guard clauses as loop-body conditionals. Early exits from loops keep loop bodies clean and imperative.

Colony Creatures

Prototype-based object-oriented programming. A colony block is a prototype object; grows performs prototypal inheritance via Object.create + Object.assign. Methods use self to refer to the current instance — contextually checked at compile time.

Graph Traversal

First-class weighted graphs with graph [~ node … edge … weight … ~]. spread … from … reach performs a breadth-first traversal. The compiler verifies at analysis time that the spread target is a graph-typed variable.

Network Paths

Combines graphs, colonies, and BFS traversal in one program. A colony tracks visit statistics while spread walks the graph — demonstrating how Moss's primitives compose naturally.
