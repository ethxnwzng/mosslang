The language

Code that reads like nature grows

Moss is a dynamically typed scripting language with four compiler phases — parse, analyze, optimize, and generate — that targets JavaScript. Every keyword was chosen to feel like something alive: things sprout, functions grow, results bloom.

🌿

Nature-first keywords

grow declares functions. sprout declares variables. bloom prints. harvest returns. Every word has a reason.

🔗

Pipeline operator

Chain calls left-to-right with ~>: x ~> double ~> show reads exactly like a data flow — no nested parentheses.

🛡

Guard clauses

One-armed conditionals with =>: n <= 0 => harvest 0 keeps early exits crisp and readable.

🌳

Prototype colonies

Objects are colony blocks. Inheritance is grows. No class keyword, no new — just living prototypes.

📊

First-class graphs

Declare weighted graphs inline with graph [~ node … edge … ~] and traverse them with spread … from … reach.

⚡

Compile-time analysis

Static checks for scope, harvest outside functions, self outside colonies, and type-correct spread targets.

Reading Moss

Every color tells you what a word does

Moss uses two symbolic operators (<~ and ~>) and two keyword families — things that begin and things that end. The colors below are consistent across every example on this site.

grow  sprout  colony  cycle  spread  reach — opens or declares something
harvest  bloom  wither  dormant — ends, outputs, or exits
<~  ~>  =>  [~  ~] — operators and block delimiters
"hello"  42  true — values: strings, numbers, booleans
~~ this is a comment — comments (to end of line)

Side by side

Fibonacci — Moss vs JavaScript vs Python

The same recursive Fibonacci function, written in three languages. Notice how Moss's guard clause (=>) replaces a full if/return, and cycle replaces while.

Moss
JavaScript
function fib(n) {
  if (n <= 1) return n;
  return fib(n - 1) + fib(n - 2);
}

let i = 0;
while (i <= 10) {
  console.log(fib(i));
  i++;
}
Python
def fib(n):
    if n <= 1:
        return n
    return fib(n - 1) + fib(n - 2)

i = 0
while i <= 10:
    print(fib(i))
    i += 1
