The idea

Grow from a single spore

Moss is a naturally reproducing organism. It spreads from a single point, building dense networks through growth and inheritance — no seeds, no roots, just connection. Code that prioritizes reusable, composable pieces follows the same pattern: a project grows from its starting pieces.

This makes Moss especially well-suited for graph problems. Any problem that can be modeled as nodes and connections — social networks, computer networks, routing, dependency resolution — is a problem Moss was built to express naturally.

Real-world example
Network reachability

A classic DevOps question: given a network topology, which servers are reachable from a gateway? This is the backbone of tools like Kubernetes network policies, AWS VPC routing, and the core of LeetCode #1971 — Find if Path Exists in Graph. In Moss, the entire BFS traversal is a single spread block.

The language

Code that reads like nature grows

Every keyword was chosen to feel like something alive. Two families — things that open and things that close — cover the entire language.

Moss uses two keyword families and a set of symbolic operators. The colors below are consistent across every example on this site.

Under the hood

Moss compiles to clean JavaScript

Each construct maps directly to a JavaScript equivalent. Guard clauses become if statements. Colonies become object literals. Pipelines unwrap to nested calls. The output is readable, standard JS — no runtime required.
