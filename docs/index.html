The language

Code that reads like nature grows

Moss is a dynamically typed scripting language with four compiler phases — parse, analyze, optimize, and generate — that targets JavaScript. Every keyword was chosen to feel like something alive: things sprout, functions grow, results bloom.

Starters — open or declare
growdeclare a function
sproutdeclare a variable
cycleloop while condition holds
whenconditional block
otherwiseelse branch of when
colonycreate a prototype object
growsinherit from a colony
selfcurrent object inside a method
graphfirst-class weighted graph
spreadBFS traversal over a graph
reachcallback for each visited node
Enders — output or exit
bloomprint a value to output
harvestreturn a value from a function
witherbreak out of a loop
dormantskip to the next iteration
Operators
<~assign (value flows left)
~>pipe into a function (left-to-right)
=>guard — run if condition is true
[~  ~]open and close a block
~~comment to end of line

Reading Moss

Moss uses two keyword families and a set of symbolic operators. The colors below are consistent across every example on this site.

grow  sprout  colony  cycle  spread  reach — opens or declares something
harvest  bloom  wither  dormant — ends, outputs, or exits
<~  ~>  =>  [~  ~] — operators and block delimiters
"hello"  42  true — values: strings, numbers, booleans
~~ this is a comment — comments (to end of line)
