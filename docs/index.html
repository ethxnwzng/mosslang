A nature-inspired scripting language that compiles to JavaScript.

Moss is named after the naturally reproductive organism, growing in colonies and spreading across connected surfaces through small, interlocking bits. Building a project and doing computation on graph problems work the same way — connected nodes, reachable from a root, traversed in structured paths. Moss makes graphs first-class syntax: declare them, traverse them, in one readable block.

Under the hood

Moss compiles to clean JavaScript

Each construct maps directly to a JavaScript equivalent — no runtime required.

Parser
Ohm.js matches source against the formal grammar in moss.ohm and builds a typed AST
  • Operator precedence encoded across 7 expression levels (Exp → Exp7)
  • Each rule produces a typed node — FunDecl, GraphLit, PipeExp, CycleStmt
→
Analyzer
Walks the AST with a parent-chained lexical scope stack
  • Tracks four context flags: inFunction, inLoop, inColony, inSpread
  • Enforces contextual rules — harvest outside grow, spread on non-graphs, argument count mismatches
  • Type-tags variables: GraphLit → graph, ColonyLit → colony
→
Optimizer
Transforms the AST to eliminate unnecessary work before code generation
  • Constant folds numeric and boolean expressions at compile time (2 + 3 → 5)
  • Dead branch removal: when true inlines the block, cycle false → empty
  • Trims unreachable statements after harvest, wither, or dormant
→
Generator
Walks the optimized AST and emits JavaScript strings
  • spread/reach expands to a full BFS — queue, visited Set, adjacency Map
  • grows emits Object.assign(Object.create(…)); self becomes this
  • bloom → console.log, harvest → return, wither → break
